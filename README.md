\# Civic Connect



A Crowdsourced Civic Issue Reporting and Resolution System developed for Smart India Hackathon 2026.



\## About the Project



Civic Connect allows citizens to report civic issues such as damaged roads, garbage, streetlight problems, drainage issues, and other public infrastructure problems.



Users can submit an issue with:

\- Description

\- Photo

\- Location



The system analyzes the complaint and helps administrators prioritize and resolve civic issues.



\## Main Features



\- Gmail OTP based login

\- Civic issue reporting

\- Photo upload

\- Location capture

\- AI-based complaint analysis

\- Multiple AI provider integration

\- Complaint priority detection

\- Duplicate complaint analysis

\- Admin dashboard

\- Complaint status tracking

\- User blocking and unblocking

\- User feedback

\- Email notifications

\- Google Maps location view
